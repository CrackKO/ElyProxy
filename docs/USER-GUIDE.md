## Подписки и серверы

### Добавление подписки

Откройте **Серверы → ＋ Добавить → Добавить подписку**. Укажите имя и HTTP/HTTPS-ссылку, предоставленную вашим провайдером. ElyProxy умеет читать обычные списки ссылок, base64, Clash YAML и JSON-конфигурации Xray/sing-box, в том числе массивы полных конфигов с именами из `remarks`.

У каждой подписки можно задать:

| Параметр | Зачем нужен |
| :-- | :-- |
| **User-Agent** | Когда провайдер выдаёт разные форматы разным клиентам. Доступны готовые пресеты, включая Happ, v2rayN и Shadowrocket. |
| **HWID / X-Hwid** | Когда провайдер требует идентификатор устройства. Используйте значение по его инструкции. |
| **HTTP-заголовки** | Для дополнительных требований конкретного сервиса. |
| **Интервал обновления** | Собственное расписание вместо общего интервала приложения. |
| **Фильтр и сортировка** | Для отбора серверов и порядка списка при обновлении. |

Параметры задаются при добавлении или через контекстное меню подписки. Кнопка **Обновить все** запрашивает подписки заново. При ошибке обновления приложение сохраняет прежние серверы; если фильтр не нашёл ничего, прежний список также сохраняется.

Если провайдер возвращает заголовок `subscription-userinfo`, ElyProxy показывает использование трафика и срок действия. Приложение предупреждает при использовании 80% трафика и приближении окончания подписки к трём дням. Без данных от провайдера эти показатели недоступны.

### Поиск и подключение

На экране **Серверы** выберите одну подписку, **Все подписки** или **Вручную**. Поиск, страна, протокол и вкладки **Все / Избранное / Недавние** работают совместно. Доступна сортировка по имени и задержке.

Звезда добавляет сервер в избранное. В недавних сохраняются последние 30 успешных подключений. Переименование сервера при обновлении подписки не сбрасывает избранное. Переключение подписки или фильтра само по себе не разрывает активное соединение.

Выберите сервер и нажмите **Подключить**, дважды щёлкните строку или нажмите `Enter`. Панель подключения показывает активный сервер, режим и время сессии. Скорость и суммарный трафик доступны для поддерживаемых ядер через sing-box Clash API.

### Ручной сервер, профили и экспорт

Для отдельной ссылки выберите **＋ Добавить → Добавить сервер вручную**. Например, можно вставить ссылку `vless://`, `vmess://`, `trojan://`, `ss://`, `hysteria2://` или `tuic://` от провайдера.

Контекстное меню строки открывается через `⋯` или правый клик. В нём есть подключение, избранное, добавление в профиль, копирование прокси и **Поделиться…**. Обмен поддерживает ссылки и QR-коды, Clash YAML и JSON с Xray outbounds. В разделе **Профили** можно хранить собственные наборы серверов, импортировать Clash YAML/JSON и переносить профили в формате `.elyproxy`.

Ссылка или QR-код могут содержать данные доступа. Передавайте их только тем, кому хотите дать доступ к серверу.

## Маршрутизация и ElyTun

### Выбор режима

- **Proxy Lite** использует Xray и PAC Windows. Подходит приложениям с поддержкой системного PAC; не определяет процесс-источник и не применяет правила по приложениям.
- **Proxy Pro** использует sing-box и системный HTTP/HTTPS/SOCKS-прокси. Правила действуют на трафик, который приложения отправляют в этот прокси.
- **ElyTun** создаёт TUN-интерфейс и меняет маршрутизацию системного трафика. Подходит программам без поддержки системного прокси.

Режимы взаимоисключаются. Для ручной настройки приложения используйте SOCKS5 `127.0.0.1:1080`; при изменении локального порта укажите новое значение.

### Свои правила

Откройте **Настройки → Разделение трафика**. Указывайте каждое правило с новой строки. Домен или wildcard отправляет соответствующие запросы напрямую; IP/CIDR задаёт прямой маршрут. Например:

```text
*.ru
*.рф
*.xn--p1ai
*.su
*.com.ru
*.edu.ru
```

Эти доменные зоны входят в исходный список обхода. Они открываются напрямую, если выбран режим и профиль, применяющий ваши правила. Удалите ненужное правило, чтобы изменить этот маршрут.

Для предсказуемого TUN используйте домены и IP/CIDR. `geoip:` и произвольные `geosite:` — правила Xray-режима; не все ядра поддерживают одинаковый синтаксис.

### RoscomVPN DEFAULT

В **Профиле маршрутизации ElyTun** можно выбрать **Свои правила** или **RoscomVPN DEFAULT**.

Готовый пресет основан на [roscomvpn-routing](https://github.com/hydraponique/roscomvpn-routing) и включает блокировку категорий `win-spy`, `torrent`, `category-ads`, прокси-маршруты для Google Play, GitHub, Twitch Ads, YouTube и Telegram, прямые маршруты для private/RU и набора российских и игровых сервисов. Это маршруты по включённым наборам правил, а не обещание классифицировать любой трафик.

22 sing-box rule-set-файла включены в `Assets/RoscomVPN/`; скачивать их при подключении не нужно. В пресет перенесены DNS-хосты и DoH-серверы DEFAULT: Yandex DNS для direct-категорий и Google DoH через прокси для остальных запросов. Смена профиля при активном ElyTun перезапускает соединение с новой конфигурацией.

Включённый снимок данных:

| Набор | Ревизия |
| :-- | :-- |
| routing | `cbbf6ef2b967365054786991cff5d72c9bbda345` |
| geoip | `7b501f88754c9365e6a9fd6d9db6ee8423a80507` |
| geosite | `8e77ecb1162be9bbc8355c2cd45dd6772f1a1627` |

### Правила по приложениям

Выберите исполняемые файлы `.exe` в настройках маршрутизации. Есть два подхода:

| Режим | Результат |
| :-- | :-- |
| **Обход выбранных приложений** | Выбранные приложения идут напрямую. |
| **Только выбранные приложения** | Через прокси направляются выбранные приложения, остальное идёт напрямую. |

Правила по приложениям имеют приоритет над доменными/IP-правилами и пресетом. Для применения изменений к активному соединению отключитесь и подключитесь снова.

Поддержка зависит от ядра. Proxy Lite и tun2proxy не поддерживают такие правила. При пустом списке в режиме «только выбранные» или несовместимом ядре ElyProxy откажет в подключении и покажет причину. В Proxy Pro правило может обработать только трафик, поступающий в системный прокси.

### TUN-ядро и права

В настройках ElyTun можно выбрать **sing-box** (по умолчанию), **Xray**, **tun2proxy** или **Hysteria 2**. Последний вариант предназначен для Hysteria2-серверов. tun2proxy использует локальный бэкенд; для Hysteria2 его движок также можно выбрать отдельно.

ElyProxy запускается без повышения прав. При включении TUN потребуется системный запрос UAC. Необязательная **Служба-помощник** в настройках ElyTun запускает ядра с необходимыми правами; её установка требует повышения прав, после чего работающая служба позволяет подключать TUN без UAC каждый раз.

В sing-box ElyTun локальные/private-адреса и сети активных Windows-адаптеров исключаются из TUN-маршрута. Это помогает сохранить доступ к локальной сети, Radmin VPN и другим параллельным интерфейсам. Адрес сервера также исключается, чтобы подключение не зацикливалось. IPv6 настраивается отдельно; MTU использует внутреннее безопасное значение.

Для своих правил DNS разделяется: домены обхода запрашиваются напрямую, остальные — через DoH в прокси. У разных TUN-ядер различаются возможности; не переносите ожидания от sing-box на tun2proxy автоматически.

Если одновременно запущен zapret/winws, исключите IP сервера из его WinDivert-фильтра. ElyProxy не изменяет настройки сторонней программы автоматически.

### Обход DPI

Доступны фрагментация TLS, noise-пакеты и настройки подмены ClientHello/SNI. Реализация и совместимость зависят от ядра: VLESS Encryption, xhttp и mKCP требуют Xray, TLS spoof использует sing-box и требует прав администратора. NaiveProxy требует `libcronet.dll`, ShadowTLS — корректную цепочку с Shadowsocks.

Начните с настроек по умолчанию. Меняйте один параметр за раз и переподключайтесь, затем проверяйте результат. Эти функции не гарантируют обход любой фильтрации.

## Проверка соединения

Тип проверки выбирается в настройках; запуск — кнопкой **Проверить задержку** в разделе серверов. Проверяются все серверы, включая скрытые фильтрами.

| Тип | Что проверяется |
| :-- | :-- |
| **TCP-пинг** | Соединение с адресом и портом. Быстро, но не проверяет авторизацию и маршрут через прокси. |
| **Proxy GET** | HTTP GET через временный локальный прокси. URL по умолчанию — `https://youtube.com`; его можно изменить. |
| **ElyTurbo** | Проверочные адреса Discord, Telegram, YouTube, Spotify, GitHub и Gmail. Учитываются доступность сервисов и средняя задержка; лучший кандидат выбирается в списке. |
| **ElyHard** | Повторные обращения к сервисам через временный прокси. Рейтинг учитывает стабильные сервисы, успешные попытки и задержку. |

Количество потоков для проверок задаётся в настройках. Большие значения создают больше параллельных процессов и запросов. Эти проверки не являются измерением максимальной скорости загрузки или проверкой всех функций сервиса.

**Диагностика** отдельно проверяет ядро, локальный порт, настройки Windows и внешний HTTPS-маршрут. Отчёт можно скопировать без UUID и ссылок подписок. Для подробностей откройте журнал (`Ctrl+L`).

Сообщение **«HTTPS не подтверждён»** означает, что проверочные адреса не ответили. Само по себе оно не доказывает отсутствие интернета: откройте нужный сайт и выполните диагностику.

## Обновления

### Клиент

Откройте **Настройки → Обновления**, проверьте наличие версии и следуйте предложению приложения. Встроенный апдейтер получает manifest с сервера проекта, проверяет размер и SHA-256 ZIP-пакета, завершает клиент, заменяет файлы и запускает приложение снова.

Если встроенная проверка недоступна, скачайте полный архив из [GitHub Releases](https://github.com/CrackKO/ElyProxy/releases/latest). Закройте ElyProxy, включая значок в трее, и распакуйте новую версию в отдельную постоянную папку. Пользовательские данные хранятся отдельно в `%AppData%\ElyProxy\`.

### Ядра и geo-данные

1. Отключите соединение.
2. Откройте **Настройки → Ядра**.
3. Проверьте обновления и установите нужные ядра.
4. Подключитесь снова.

Ядра скачиваются из релизов соответствующих проектов на GitHub и устанавливаются в `%LocalAppData%\ElyProxy\cores\`. Проверка SHA-256 выполняется, когда GitHub API предоставляет digest. После установки запускается проверка версии; при неудаче восстанавливается резервная копия. Пользовательские ядра имеют приоритет над файлами рядом с приложением.

Отдельная **Hysteria 2** устанавливается через этот раздел, если выбран соответствующий движок или TUN-провайдер. При необходимости NaiveProxy обновите sing-box вместе с `libcronet.dll`.

Кнопка **Обновить geo-данные** обновляет `geoip.dat` и `geosite.dat` Xray из Loyalsoldier/v2ray-rules-dat. Файлы устанавливаются рядом с активным `xray.exe`. Последующее обновление Xray может заменить их версиями из своего релиза. Встроенные rule-set-файлы RoscomVPN обновляются вместе с ElyProxy.

## Защита подписки

Переключатель **Блокировать Torrent** находится в **Настройки → Защита подписки**.

**При включении ElyProxy принудительно завершает обнаруженные процессы поддерживаемых торрент-клиентов.** Проверка повторяется каждую секунду, пока программа открыта, в том числе в трее и без активного VPN. Загрузки прерываются. Если клиент нельзя закрыть перед подключением, подключение отменяется с уведомлением и записью в журнале.

Распознавание основано на именах процессов, включая qBittorrent, µTorrent, BitTorrent, Transmission, Deluge, Tixati, BitComet, BiglyBT, Vuze, PicoTorrent, WebTorrent, aria2, Motrix и MediaGet. Переименованные клиенты, общие Java-процессы и браузерные торренты могут не распознаваться. Клиент с повышенными правами может потребовать ручного закрытия.

Это контроль известных процессов, а не сетевой фильтр BitTorrent и не гарантия соблюдения условий провайдера. Он отличается от категории `torrent` в пресете маршрутизации RoscomVPN.

## Оформление и горячие клавиши

В настройках можно выбрать системную, светлую или тёмную тему, изменить поведение анимаций и показ журнала. При высокой контрастности Windows приложение использует системные цвета. У новых установок тёмная тема и свёрнутый журнал; существующие настройки сохраняются.

| Клавиши | Действие |
| :-- | :-- |
| `Ctrl+1` | Серверы |
| `Ctrl+2` | Подписки |
| `Ctrl+3` | Профили |
| `Ctrl+4` | Настройки |
| `Ctrl+F` | Поиск серверов |
| `Ctrl+L` | Показать или скрыть журнал |
| `Enter` | Подключить выбранный сервер в списке |

Также доступны автозапуск с Windows, автоподключение к последнему серверу, переподключение после сбоя и расписание обновления подписок. Повторный запуск ElyProxy активирует уже открытое окно.

## Хранение данных

| Путь | Содержимое |
| :-- | :-- |
| `%AppData%\ElyProxy\subscriptions.json` | Подписки и их серверы |
| `%AppData%\ElyProxy\profiles.json` | Пользовательские профили |
| `%AppData%\ElyProxy\settings.json` | Настройки, ручные серверы и правила |
| `%LocalAppData%\ElyProxy\cores\` | Ядра, установленные через приложение |
| `%LocalAppData%\ElyProxy\service\` | Установленная служба-помощник |
| `%LocalAppData%\ElyProxy\crash.log` | Записи необработанных ошибок, если они возникли |
| `%LocalAppData%\ElyProxy\updater.log` | Журнал отдельного апдейтера |

Для резервной копии закройте приложение и скопируйте всю папку `%AppData%\ElyProxy\`. Файлы могут содержать данные доступа — не прикладывайте их целиком к публичным сообщениям об ошибках.

## Решение проблем

| Симптом | Что сделать |
| :-- | :-- |
| **Программа просит установить .NET** | Установите **.NET 8 Desktop Runtime x64**, затем запустите повторно. Обычный Runtime без Desktop-компонентов не заменяет WPF runtime. |
| **Не загрузилась подписка** | Проверьте ссылку, срок действия, User-Agent, HWID и заголовки по инструкции провайдера. Прежние серверы при ошибке обновления сохраняются. |
| **Ядро не найдено** | Распакуйте весь официальный архив. Проверьте папки ядер или установите нужное ядро через **Настройки → Ядра**. |
| **Протокол или транспорт не поддерживается** | Для xhttp, mKCP и VLESS Encryption выберите Xray; для Hysteria2/TUIC/AnyTLS — sing-box или подходящий специализированный движок. Сверьтесь с сообщением приложения. |
| **Браузер работает, а другая программа — нет** | Она может игнорировать системный прокси. Настройте SOCKS5 вручную или выберите ElyTun. |
| **Отдельный сайт идёт напрямую** | Проверьте свои правила, профиль RoscomVPN и список приложений. Российские зоны входят в исходные bypass-правила. |
| **TCP-пинг есть, но сайты не открываются** | Выполните Proxy GET и **Диагностику**: открытый порт не подтверждает работу прокси. |
| **ElyTun требует администратора** | Разрешите системный запрос UAC либо установите и включите службу-помощник. |
| **Изменения правил не применились** | Отключитесь и подключитесь заново. |
| **После аварии не работают сайты** | Проверьте настройки прокси Windows и выключите оставшийся прокси. Для проблемы TUN запустите ElyProxy с необходимыми правами и отключите соединение; если сеть не восстановилась, перезагрузите Windows. |
| **Обновление не скачивается** | Используйте полный архив из GitHub Releases; перед ручной заменой закройте клиент. |

Если проблема остаётся, напишите в [Discord](https://discord.gg/sxjV3S7J2k) или создайте [Issue](https://github.com/CrackKO/ElyProxy/issues). Укажите версию, Windows, режим/ядро, последовательность действий и отчёт диагностики. Проверьте прикладываемые материалы на наличие секретов.
