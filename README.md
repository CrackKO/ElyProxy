# ElyProxy

Windows-клиент для прокси-подписок на базе Xray-core, sing-box и Hysteria 2. Приложение поднимает локальный SOCKS5-прокси, поддерживает VLESS (Reality, WS/CDN, xhttp, mKCP), VMess, Trojan, Shadowsocks, Hysteria2, TUIC, AnyTLS, SSH, WireGuard, NaiveProxy и ShadowTLS, умеет работать с подписками (ссылки, Clash YAML, JSON), включать системный прокси Windows с разделением трафика и запускать ElyTun для полного TUN-режима.

## Быстрый доступ и блокировка Torrent

На экране серверов доступны добавление подписки, поиск (`Ctrl+F`), фильтр всех протоколов,
сортировка и подключение прямо из строки. Двойной щелчок или `Enter` подключает выбранный
сервер. `Ctrl+1…4` переключают разделы; `Ctrl+L` открывает журнал. В настройках есть
быстрые переходы к группам параметров. У новых установок журнал изначально свёрнут.

Переключатель **«Блокировать Torrent»** находится только в настройках, в группе «Защита подписки».
Он сохраняется между запусками и принудительно завершает известные торрент-клиенты
сразу после включения и при повторном запуске (проверка каждую секунду), даже без VPN.
Загрузки прерываются. Контроль работает, пока ElyProxy открыт, в том числе в трее.
Перед подключением выполняется дополнительная проверка: если клиент невозможно
закрыть, подключение отменяется, выводятся уведомление и запись в журнале.

Распознавание основано на точных именах процессов (qBittorrent, µTorrent, BitTorrent,
Transmission, Deluge, Tixati, BitComet, BiglyBT, Vuze, PicoTorrent, WebTorrent,
aria2, Motrix, MediaGet и другие). Переименованные клиенты, Java-процессы с общим
именем и встроенные браузерные торренты не распознаются. Это не блокировка сетевого
протокола и не гарантия от санкций VPN-сервиса. Клиент с повышенными правами может
потребовать ручного закрытия или запуска ElyProxy от администратора.

Самопроверка ElyTun обращается к двум независимым HTTPS-адресам. Сообщение
«HTTPS не подтверждён» означает, что проверочные адреса не ответили; оно само
по себе не доказывает отсутствие интернета. Проверьте сайты и выполните
«Диагностику»: безопасный отчёт поможет отделить проблему ядра от DNS/маршрута.

## Протоколы и ядра

| Ядро | Протоколы | Где применяется |
|------|-----------|-----------------|
| Xray-core | VLESS, VMess, Trojan, Shadowsocks, SOCKS/HTTP | Proxy Lite, Xray TUN, tun2proxy |
| sing-box | всё выше + Hysteria2, TUIC, AnyTLS, SSH, WireGuard, NaiveProxy, ShadowTLS | Proxy Pro, ElyTun, tun2proxy |

## Системный Прокси

Режим **Системный прокси** включает PAC-конфигурацию в настройках Windows. Это позволяет направлять через прокси только нужный трафик, а часть доменов открывать напрямую.

По умолчанию напрямую идут домены:

```text
*.ru
*.рф
*.xn--p1ai
*.su
*.com.ru
*.edu.ru
```

Правила можно изменить во вкладке **Настройки** → **Разделение трафика**. Каждое правило указывается с новой строки.

Важно:

- системный прокси активируется только после подключения к серверу;
- при отключении от сервера системный прокси выключается;
- если режим был включён до отключения, он автоматически активируется снова после следующего подключения.

## ElyTun

### RoscomVPN DEFAULT (встроенный пресет)

В настройках **Разделение трафика** → **Профиль маршрутизации ElyTun** можно
выбрать один из двух вариантов:

- **Свои правила** — текущий редактируемый список bypass-правил приложения.
- **RoscomVPN DEFAULT** — готовый пресет, повторяющий логику
  [hydraponique/roscomvpn-routing](https://github.com/hydraponique/roscomvpn-routing)
  для HAPP DEFAULT: блокировка `win-spy`, `torrent`, `category-ads`; прокси для
  Google Play, GitHub, Twitch Ads, YouTube и Telegram; прямой маршрут для
  private/RU и набора российских и игровых сервисов.

Для готового пресета в сборку уже включены 22 локальных sing-box rule-set'а в
`Assets/RoscomVPN/`, поэтому пользователь ничего не скачивает во время работы.
DNS-хосты и DoH-серверы из DEFAULT также перенесены: Yandex DNS для direct-
категорий и Google DoH через прокси для остальных запросов. При смене профиля
во время активного ElyTun приложение сначала останавливает sing-box, применяет
новую конфигурацию и подключается снова.

Снимок данных в этой версии: routing
`cbbf6ef2b967365054786991cff5d72c9bbda345`, geoip
`7b501f88754c9365e6a9fd6d9db6ee8423a80507`, geosite
`8e77ecb1162be9bbc8355c2cd45dd6772f1a1627`. Лицензия набора geosite сохранена
в `Assets/RoscomVPN/LICENSE-RoscomVPN-Geosite.txt`.

**ElyTun** — режим полного системного туннеля на базе sing-box. Он использует Windows `auto_route`, создаёт TUN-интерфейс и направляет системный IPv4- и, при включённой настройке, IPv6-трафик через выбранный сервер. Локальные/private-адреса и сети активных адаптеров Windows исключаются из маршрута TUN, чтобы не ломать доступ к локальной сети, Radmin VPN и другим параллельным интерфейсам.

Особенности:

- ElyProxy запускается без прав администратора, поэтому автозапуск Windows работает без UAC; при выборе ElyTun приложение запросит повышение прав и перезапустится через системный запрос Windows;
- ElyTun и **Системный прокси** взаимоисключаются;
- для ElyTun нужен `sing-box.exe` в папке `sing-box/` рядом с приложением; обычный SOCKS5-режим продолжает использовать Xray;
- Radmin VPN, Happ, Wintun, WireGuard, OpenVPN и похожие адаптеры не блокируют запуск; их локальные сети добавляются в direct-маршруты TUN;
- системные Windows-туннели вроде Teredo не блокируют запуск ElyTun;
- перед включением TUN IP-адрес VLESS-сервера определяется и исключается из TUN-маршрута, поэтому транспорт к серверу не зацикливается;
- MTU использует внутреннее безопасное значение; IPv6 настраивается во вкладке **Настройки**;
- DNS разделён: домены из bypass-правил запрашиваются у DNS активного адаптера напрямую, остальные — через DoH внутри VLESS. Это исключает многосетевые DNS-петли Windows.
- список **Обход по приложениям** направляет выбранные исполняемые файлы напрямую и имеет приоритет над доменными/IP-правилами и пресетом RoscomVPN; в Proxy Pro правило действует на трафик, поступающий в системный прокси; для изменений активного соединения отключите и снова подключите VPN;
- обход по приложениям также работает в **Proxy Pro**; **Proxy Lite** использует системный PAC, который не получает информацию о процессе-источнике.

sing-box автоматически определяет исходящий интерфейс и применяет `route_exclude_address` для private-сетей и сетей активных адаптеров. Список **Разделение трафика** применяется и в ElyTun: домены/wildcard направляются напрямую и получают прямой DNS, а IP/CIDR — как прямые маршруты и исключения из TUN. Для предсказуемого TUN используйте домены и IP/CIDR; `geoip:` и произвольные `geosite:` остаются правилами Xray-режима.

> Если запущен zapret/winws, исключите IP-адрес VLESS-сервера из его WinDivert-фильтра. ElyProxy подсказывает об этом в логе, но не меняет конфигурацию сторонней программы автоматически.

## Установка

### Готовая Сборка

1. Перейдите в [Releases](https://github.com/CrackKO/ElyProxy/releases)
2. Скачайте архив `ElyProxy-X.Y.Z-win-x64.zip` из [последнего релиза ElyProxy](https://github.com/CrackKO/ElyProxy/releases/latest).
3. Распакуйте архив в постоянную папку, например `%LocalAppData%\Programs\ElyProxy`, и запустите `ElyProxy.exe`.
4. В официальном архиве должны быть папки `xray/`, `sing-box/`, `updater/` и `Assets/RoscomVPN/`. Если чего-то нет, скачайте архив ещё раз или используйте предыдущий релиз.
5. Если Windows сообщит об отсутствии .NET, установите **.NET 8 Desktop Runtime x64** и запустите ElyProxy повторно.

В режимах **SOCKS5** и **Proxy Lite** используется Xray; **Proxy Pro** и **ElyTun** используют sing-box. В официальной сборке оба ядра уже приложены. Для локальной сборки из исходников поместите официальные файлы Xray в `xray/` рядом с проектом, а `sing-box.exe` версии 1.13.0 или новее — в `sing-box/`:

```text
xray/xray.exe
xray/geoip.dat
xray/geosite.dat
xray/wintun.dll
sing-box/sing-box.exe
```

Для **ElyTun** нужны права администратора: ElyProxy запросит их в отдельном системном окне при включении режима. Автозапуск самого ElyProxy работает без повышения прав.

### Сборка Из Исходников

```bash
git clone https://github.com/CrackKO/ElyProxy.git
cd ElyProxy
dotnet restore
dotnet build
dotnet run
```

Release-сборка:

```bash
dotnet publish -c Release -r win-x64 --self-contained false -o publish
```

## Использование

1. На пустом экране **Серверы** нажмите **Добавить подписку** и вставьте HTTP/HTTPS-ссылку, которая возвращает список `vless://`.
2. Выберите сервер и нажмите **Подключить**.
3. Выберите режим подключения. **Proxy Lite** использует PAC и правила доменов, **Proxy Pro** задаёт системный HTTP/HTTPS/SOCKS-прокси, **ElyTun** маршрутизирует системный трафик через TUN.
4. При проблеме нажмите **Проверить соединение**. Отчёт отдельно показывает состояние ядра, локального порта, настройки Windows и внешний HTTPS-маршрут; его можно скопировать без UUID и ссылок подписок.

Для приложений, где прокси нужно указать вручную:

```text
socks5://127.0.0.1:1080
```

Кнопка **Пинг** на вкладке **Серверы** использует режим, выбранный в настройках:

- **TCP пинг** — быстрый замер подключения до адреса и порта сервера;
- **Proxy GET** — параллельный запуск временных Xray-проверок и GET-запрос через прокси, чтобы проверить реальную работу маршрута. URL по умолчанию: `https://youtube.com`.
- **ElyTurbo** — проверка Discord, Telegram, YouTube, Spotify, GitHub и Gmail. Сначала учитывается количество доступных сервисов, затем средняя задержка. Лучший сервер автоматически выбирается в списке.
- **ElyHard** — полный real-session тест: для каждого сервера запускается временный Xray, затем Discord, Telegram, YouTube, Spotify, GitHub и Gmail открываются через этот прокси в несколько попыток. Рейтинг учитывает стабильные сервисы, успешные попытки и задержку.

## Настройки

В разделе **Настройки** доступны:

- тема оформления: как в системе, светлая или тёмная;
- анимации: как в системе, включены или выключены;
- при включённой теме высокой контрастности Windows интерфейс автоматически переключается на системные цвета;
- показ или скрытие журнала (также `Ctrl+L`);
- запуск вместе с Windows;
- подключение к последнему серверу;
- переподключение при обрыве;
- локальный SOCKS5-порт;
- тип пинга для кнопки **Пинг**;
- URL для Proxy GET-пинга;
- количество потоков для Proxy GET, ElyTurbo и ElyHard;
- интервал автообновления подписок;
- профиль маршрутизации ElyTun, правила разделения трафика и список приложений для прямого подключения в ElyTun/Proxy Pro.

Разделы переключаются боковой панелью, горячие клавиши `Ctrl+1`…`Ctrl+4` открывают
Серверы, Подписки, Профили и Настройки соответственно.

## Хранение Данных

Данные хранятся в:

```text
%AppData%/ElyProxy/
```

Основные файлы:

- `subscriptions.json` — подписки и серверы из подписок;
- `profiles.json` — пользовательские профили;
- `settings.json` — настройки, ручные серверы, правила системного прокси и состояние ElyTun.

## Примечания

- Для работы системного прокси приложение меняет пользовательские настройки Windows Internet Settings.
- При выключении системного прокси приложение пытается восстановить предыдущее значение `AutoConfigURL`.
- Если приложение было завершено аварийно, системный прокси можно отключить вручную в настройках Windows.
- Для ElyTun приложение запускает sing-box TUN inbound с автоматической маршрутизацией Windows, поэтому нужны права администратора.
- Если ElyTun был аварийно завершён и сеть ведёт себя странно, перезапустите ElyProxy от имени администратора и нажмите **Отключить** либо перезагрузите Windows.
