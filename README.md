ElyProxy собирает подписки, серверы и правила подключения в одном приложении: от локального SOCKS5 до ElyTun для системного трафика. Найдите подходящий сервер, проверьте его доступность и выберите, какие сайты и приложения подключать через прокси.

> **Для подключения нужна ваша подписка или конфигурация сервера.** ElyProxy — клиент; приложение само по себе не выдаёт VPN-серверы или доступ к ним.

## Установка

**Требования:** Windows x64 и **.NET 8 Desktop Runtime x64**. Клиент использует WPF; сборка для Linux/macOS в этом репозитории не предусмотрена.

1. Откройте **[последний релиз](https://github.com/CrackKO/ElyProxy/releases/latest)**.
2. В разделе **Assets** скачайте `ElyProxy-X.Y.Z-win-x64.zip` — готовую программу, а не архив `Source code`.
3. Распакуйте **весь архив** в постоянную папку, например `%LocalAppData%\Programs\ElyProxy`.
4. Запустите `ElyProxy.exe`. Если Windows попросит .NET, установите [**.NET 8 Desktop Runtime для Windows x64**](https://dotnet.microsoft.com/en-us/download/dotnet/8.0) и повторите запуск.

Сохраняйте папки ядер, `updater`, `helper` и `Assets` рядом с программой. Перенос одного `ElyProxy.exe` не заменяет распаковку полного пакета.

> Для обычного запуска права администратора не нужны. ElyTun запросит повышение прав при включении; необязательная служба-помощник позволяет затем подключать TUN без повторных запросов UAC.

## Первое подключение

1. На экране **Серверы** нажмите **＋ Добавить → Добавить подписку** и вставьте ссылку от своего провайдера. Для отдельной ссылки выберите **Добавить сервер вручную**.
2. Дождитесь загрузки серверов. При необходимости используйте поиск или фильтры.
3. В панели подключения выберите режим: **Proxy Lite**, **Proxy Pro** или **ElyTun**.
4. Выберите сервер и нажмите **Подключить**. Двойной щелчок или `Enter` также подключает выбранный сервер.
5. Проверьте нужный сайт или приложение. Если что-то не работает, нажмите **Диагностика** на экране серверов.

Для приложения с собственной настройкой прокси укажите **SOCKS5**, адрес `127.0.0.1`, порт `1080` (по умолчанию). Порт можно изменить в настройках ElyProxy.

## Режимы подключения

| Режим | Как работает | Когда выбрать |
| :-- | :-- | :-- |
| **Proxy Lite** | Xray + системный PAC Windows. Доменные правила определяют прямой маршрут. | Для браузера и приложений, которые поддерживают системный PAC. |
| **Proxy Pro** | sing-box + системный HTTP/HTTPS/SOCKS-прокси. Поддерживает правила по приложениям для трафика, поступающего в прокси. | Если нужна совместимость с протоколами sing-box и более гибкие правила. |
| **ElyTun** | TUN-интерфейс и системная маршрутизация. Ядро выбирается в настройках. | Для приложений, которые не используют системный прокси. Нужны права администратора или работающая служба-помощник. |

Режимы взаимоисключаются. Системный прокси охватывает приложения, которые его используют; ElyTun направляет системный трафик с учётом исключений и правил. **Proxy Lite не поддерживает маршрутизацию по приложениям.**

[Разделение трафика, выбор ядра и служба-помощник →](docs/USER-GUIDE.md#маршрутизация-и-elytun)

## Протоколы и ядра

| Ядро | Поддерживаемые протоколы | Где используется |
| :-- | :-- | :-- |
| **[Xray-core](https://github.com/XTLS/Xray-core)** | VLESS, VMess, Trojan, Shadowsocks, SOCKS, HTTP | Proxy Lite, Xray TUN, бэкенд tun2proxy |
| **[sing-box](https://github.com/SagerNet/sing-box)** | Протоколы выше, Hysteria2, TUIC, AnyTLS, SSH, WireGuard, NaiveProxy, ShadowTLS | Proxy Pro, ElyTun, бэкенд tun2proxy |
| **[Hysteria 2](https://github.com/apernet/hysteria)** | Hysteria2 | Отдельный движок Hysteria2 и Hysteria TUN; устанавливается через обновление ядер |
| **[tun2proxy](https://github.com/tun2proxy/tun2proxy)** | Работает поверх локального SOCKS/mixed-бэкенда | Альтернативный TUN-провайдер |

**Совместимость зависит и от транспорта:** VLESS Encryption, xhttp и mKCP требуют Xray; NaiveProxy — `libcronet.dll` рядом с sing-box; ShadowTLS — конфигурацию цепочки Shadowsocks + ShadowTLS. Для WireGuard и таких цепочек используйте поддерживаемый JSON/Clash-импорт. Приложение сообщает, когда узел несовместим с выбранным ядром.

## Проверка серверов

| Проверка | Что показывает |
| :-- | :-- |
| **TCP-пинг** | Доступность адреса и порта сервера. Сам по себе не подтверждает работу прокси. |
| **Proxy GET** | Результат HTTP GET через временный прокси; адрес проверки задаётся в настройках. |
| **ElyTurbo** | Доступность Discord, Telegram, YouTube, Spotify, GitHub и Gmail; выбор лучшего кандидата по результатам. |
| **ElyHard** | Повторные запросы к сервисам через временный прокси, оценка стабильности и задержки. |

Выберите тип в настройках, затем нажмите **Проверить задержку**. Проверка охватывает весь список, включая серверы, скрытые фильтрами. Это результаты конкретных проверочных запросов, а не гарантия работы всех функций сервисов.

## Полезно знать

- **Свои правила** по умолчанию отправляют российские доменные зоны напрямую. Если сайт открывается без прокси, проверьте разделение трафика.
- **«Блокировать Torrent» завершает обнаруженные процессы торрент-клиентов**, пока ElyProxy открыт, даже без VPN. Это необязательная настройка, а не сетевой фильтр BitTorrent. [Подробности →](docs/USER-GUIDE.md#защита-подписки)
- Конфигурации и настройки хранятся в `%AppData%\ElyProxy\`. Перед переносом или переустановкой сохраните эту папку.
- Если после аварийного закрытия остался системный прокси, его можно выключить в настройках прокси Windows. [Решение частых проблем →](docs/USER-GUIDE.md#решение-проблем)

## Для разработчиков

Проект: **C# · .NET 8 · WPF**. Для сборки и запуска используйте Windows и .NET 8 SDK.

```powershell
git clone https://github.com/CrackKO/ElyProxy.git
cd ElyProxy
dotnet restore ElyProxy.sln
dotnet build ElyProxy.sln -c Release
dotnet run --project ElyProxy.csproj
```

Ядра нужны отдельно для реального подключения: Xray и tun2proxy не хранятся в Git. Состав пакета, расположение файлов и команды публикации описаны в [руководстве разработчика](docs/DEVELOPMENT.md).
